# 90-second video script

Record this in one take over the running app at `http://localhost:5173`. Stay under two minutes. Do not narrate every button.

**0:00–0:18 — Problem**

SaaSquatch already finds and enriches companies. After that, a searcher still has to decide who is worth a scarce owner conversation. This workspace is that decision layer: an explainable acquisition queue, not another scraper.

**0:18–0:40 — Discovery vs queue**

Show Lead discovery. Point at the raw universe, the duplicate Northstar row, and Harbor Dental’s invalid email flag. Add Summit Roofing or BrightPath to the queue. Say: operators should not treat every enriched row as a call list.

**0:40–1:05 — Score and ICP**

Open Readiness queue. Click Northstar. Walk the score breakdown. Toggle Edit ICP, change an industry, and show the table resort. The point is trust: if a searcher cannot explain the rank on a founder call, they will not use the score.

**0:05 extra if needed — Import**

If time: import `demo-leads.csv` and note that matching websites merge and queue membership is kept.

**1:05–1:35 — Action**

On a Ready-to-contact lead, scroll the first-touch draft and talking points. Copy the daily brief. Mention CRM export for HubSpot. Close: the output is not a bigger CSV. It is who to call today, why, and what to say.

**1:35–1:50 — Stack**

React and Vite on the client, Express plus SQLite with WAL on the server, Papa Parse for CSV, deterministic TypeScript for scoring. Production path is static hosting plus a containerized API on Postgres. No scraping, no CAPTCHA bypass.

**Stop.** Do not apologize for the timebox.
